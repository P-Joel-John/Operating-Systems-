# OS Lab

This repository contains programs and experiments done as part of the Operating Systems Laboratory work.

## Important

These programs are designed to work only in a **Linux environment**.


They may not work properly on Windows without WSL or a Linux system.

## How to Run

1. Open terminal in Linux
2. Compile using:
   gcc filename.c -o output
3. Run using:
   ./output

## Structure

Each experiment is organized into separate files/folders for clarity.
